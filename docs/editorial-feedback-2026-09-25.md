# Approved carousel refinement scope

Preserve the published SOON Core master, editable layers and manually saved designs.
Apply refinements only when generating/reflowing a page; never silently regenerate assets.

- Cover: semantic title breaks, not equal character counts. Group subtitle with actual title height. Safe crop/background extension remains subject-protected; black edges must not be removed by silently cutting protected subjects.
- Background page: concise background and a prominent question when narratively useful, optional second paragraph for necessary limitations. Do not impose this structure on every page.
- Explanation page: prefer one coherent scene, concise title and grouped body. Do not manufacture collages for multiple abstract concepts. A user replacement image is not evidence that the original collage can be outpainted.
- Comparison: one to three meaningful matched dimensions, not always two. Keep meaningful third rows; move non-comparable source facts to notes rather than delete them. Match peer typography and suppress empty-row decoration. Missing information is visually secondary.
- Preserve attribution, source notes, uncertainty and causal limitations. Manual copy deletions are not automatic editing rules.

Save failure reproduced as HTTP 413 at `/api/content-projects/save-design`. Embedded media must be uploaded independently and replaced by stable URLs in a cloned canvas document, including nested groups and custom metadata. No PNG quality reduction or flattening of editable text.

White page numbers/credits use a small dark contrast backing shared by PNG and editor (not pixel-based background analysis). Text packing applies to the verified 1080×1350 coordinate system; other master coordinate systems keep their geometry.

Pending visual work: full-bleed only when subject protection permits; user comparisons for P.5/P.6. Do not claim these are fixed by text packing.
